# Osobná webová stránka – WEBTE1

Autor: Nikita Porokhovyi

Web: https://webte1.fei.stuba.sk/~xporokhovyi/Z1_Porokhovyi/

Krúžok: API-8

## Obsah webu

Web obsahuje môj profil, životopis, pracovné prostredie,
týždenný rozvrh a mapu školy a domova.
Pracovné prostredie má interaktívne body, rozvrh umožňuje
filtrovanie výučby a mapa pridávanie miest s výpočtom vzdialenosti.
